# IB Math AA HL Flashcards

Anki flashcards for IB Mathematics: Analysis and Approaches HL, one subdeck per textbook chapter.

Each chapter is a subdeck under **IB Math AA HL**. New chapters are added in later updates.

## For students

### Install Anki

Use the official Anki apps:

- **Computer (Windows, Mac, Linux):** [Anki](https://apps.ankiweb.net/), free.
- **Android:** [AnkiDroid](https://play.google.com/store/apps/details?id=com.ichi2.anki), free.
- **iPhone or iPad:** [AnkiMobile](https://apps.apple.com/app/id373493387), paid.

Other apps with "Anki" in their name are not compatible with this deck.

### Download the deck

**[Download the latest deck](https://github.com/alxmjo/ib-math-aa-hl-anki/releases/latest/download/IB_Math_AA_HL.apkg)**

The link always gives the newest version. Might be worth bookmarking. 

### First import

- **Android (AnkiDroid):** tap the link, then open the downloaded file with AnkiDroid.
- **iPhone or iPad (AnkiMobile):** tap the link in Safari, open the download, tap Share and choose AnkiMobile.
- **Computer (Anki):** download the file, then use File → Import, or double-click the file.

If the import screen offers **Import any deck presets**, turn it on every time. This sets each chapter to 10 new cards per day, including chapters added in later updates. It never overwrites changes you have made to your own deck options.

The cards appear under **IB Math AA HL**, with one subdeck per chapter. Subdeck titles write the chapter with two digits (1.04, 1.14) so that Anki lists the chapters in order.

### Updating

When a new version is announced, download from the same link and import it the same way, with **Import any deck presets** turned on and the other import options at their defaults. Edited cards update in place and your review progress is kept.

### Updating from a version without chapter 1.14

Versions before chapter 1.14 named the subdecks 1.4 to 1.9; they are now 1.04 to 1.09. Anki matches subdecks by name, so rename yours once **before** importing: in the deck list, use the gear icon next to each subdeck and choose Rename, changing for example `1.4 Equations` to `1.04 Equations` (keep the rest of the name). Then import as usual.

If you imported first, you will see two copies of a chapter, such as `1.4 Equations` and `1.04 Equations`. Delete the `1.04` copy (it holds only cards new in this version), rename the `1.4` copy to `1.04`, and import again.

### Removing retired cards

Importing never deletes cards. When a card is retired, the release notes give a search such as `ID:1.4-C35 OR ID:1.4-D01`. In Anki, open Browse, paste the search, select the cards it finds and delete them.

## For maintenance

### Files

- `csv/` holds one file per chapter, with the columns id, section, type, front, back, extra, tags, active.
- `build.sh` holds the build command for every chapter and writes `dist/IB_Math_AA_HL.apkg`.
- When a chapter is added, or a card is added or retired, update the Chapters table at the top of this README.
- `build_math_deck.py` is the builder (genanki).
- `quotes.csv` gives each chapter one quote card (columns code, quote, author, source): the quote on the front, the attribution on the back, card ID `1.4-Q01` and tag `type::quote`. The builder adds it first, so it is the chapter's first new card. It already holds a quote for every chapter of Books 1 and 2; a chapter's quote card appears when that chapter is added to `build.sh`.
- `figures/` holds the SVG figures, generated by `figures/make_figures.py`. Write `[fig:NAME]` in any CSV field and the builder inlines `figures/NAME.svg`. Figures use `currentColor`, so they follow Anki's day and night colours.
- `.github/workflows/release.yml` builds the deck and attaches it to each published release.

### Conventions

- Maths uses Anki's MathJax: `\( … \)` inline, `\[ … \]` display.
- The builder keeps a short maths expression and the word attached to it on one line (`\(x\)-axis`, `\(n\)th`), and keeps punctuation with the inline maths before it (`\(x \gt 3\).`), so no markup is needed in the CSV.
- Card types: Rule and Strategy. The Why and any worked example go in Extra.
- Cloze cards put the text with `{{c1::…}}` in the front column and leave the back empty. They use the separate "IB Math cloze" note type. Keep each cloze marker outside the maths delimiters.
- Subdeck titles are the code, with the chapter zero-padded to two digits, plus the chapter name (`IB Math AA HL::1.04 Equations`), so Anki lists chapters in order. Only the title is padded: `--ref`, tags, labels and card IDs use the plain code (`1.4`, `1.4C`, `1.4-C03`).
- Anki matches subdecks by **name** on import, not by deck ID. Renaming a subdeck that students already have puts new cards in a second deck, so students must rename their copy by hand before importing.
- Tags: section code (`1.4C`) and `type::rule` or `type::strategy`. Note IDs: `1.4-C03`.
- Preset: 10 new cards per day, siblings buried.

### Never change once students have the deck

- `MODEL_ID`, `CLOZE_MODEL_ID` and `PRESET_ID` in `build_math_deck.py`.
- A chapter's `--ref` code in `build.sh`.
- Any card's `id` in a CSV. The note identity comes from the code and the card id, so edited cards update in place on re-import and students keep their progress.

### Releasing

1. Commit and push the CSV changes. This does not change what students download.
2. Test the built deck in Anki.
3. Publish a release (for example tag `v2026-10-23`). The workflow builds the deck and attaches it, and the student download link then serves the new version.
4. Retire a card by setting `active` to `no`; never delete the row. List retired IDs in the release notes as a Browse search, for example `ID:1.4-C35 OR ID:1.4-D01`.
